# Recovery and firmware safety

This document is intentionally conservative.

No firmware flashing or bootloader modification should be attempted until all of the following are documented and tested:
1. exact device and firmware identification;
2. a legitimate, device-compatible recovery route;
3. verified original firmware provenance and integrity, where legally available;
4. a safe power and connection procedure;
5. a recovery test that does not risk the owner's only device.

Do not use an image, binary or flashing command intended for another Fit3 firmware revision. Do not assume that a factory reset can recover a corrupted firmware installation.
