# LeafColor — identité visuelle commune LeafVibe

Version: 1.0

## Palette LeafColor

| Token | Hex | Usage |
|---|---|---|
| oasis | #206B4D | Couleur principale et actions |
| walnut | #6B4935 | Couleur secondaire et titres |
| natural-gold | #C5A46D | Accent et sélection ponctuelle |
| cream | #DCCBB1 | Fonds clairs et surfaces |
| sand-border | #B69A7B | Bordures et séparateurs |

Le chocolat noir, le vert sauge et l'ivoire ne font pas partie de la palette retenue.

## Règles communes
- Afficher l'icône et le nom LeafVibe dans l'en-tête lorsque l'interface le permet, avec le nom de l'application.
- Centraliser ces tokens dans un thème/module partagé plutôt que disperser les codes hexadécimaux.
- Proposer des modes clair et sombre avec contraste adapté.
- Employer le brun sable pour les bordures, l'or pour les accents et le vert Oasis pour les actions principales.
- Les couleurs sémantiques (erreur, avertissement, succès) restent distinctes.

## Adaptation des interfaces
- <600 dp : une colonne, navigation compacte et commandes tactiles.
- 600–839 dp : deux colonnes si la lisibilité le permet.
- 840–1199 dp : panneaux et zones de travail multiples.
- >=1200 dp : jusqu'à cinq colonnes/cartes si l'espace et la lisibilité le permettent.

Aucun texte vertical involontaire, élément coupé, superposition ou débordement horizontal non intentionnel. Les textes longs conservent une largeur de lecture raisonnable. Tester téléphone étroit, téléphone standard et écran large.

Cette norme doit être appliquée progressivement. Ce document ne certifie pas à lui seul que tous les écrans ont déjà été migrés ou testés.
